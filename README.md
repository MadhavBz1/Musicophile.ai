# musicophile.ai

musicophile.ai is a music discovery app designed to provide personalized music recommendations based on a user’s overall listening taste.

The app focuses on simplicity and thoughtful discovery, helping users explore music that aligns with their preferences without unnecessary complexity.

---

## Features

- Personalized music recommendations based on listening taste  
- Music search functionality  
- Clean and focused user interface  
- Backend-powered recommendation and search services

## Privacy

musicophile.ai does not collect, store, or share personal user data.

The app communicates with a server to provide recommendation and search functionality. Any information sent to the server is processed in real time and is not stored, logged, or associated with individual users or devices.

musicophile.ai does not use analytics, advertising, tracking technologies, or third-party data collection services.
